## 🔍 미션 개요

프론트엔드 애플리케이션을 구현하며, 외부 공개 API를 활용해 실제 데이터 기반의 간단한 서비스를 만든다. **API는 자유롭게 선택할 수 있으며, 본인이 만들고 싶은 간단한 서비스를 직접 기획하고 구현하면 된다.** 어떤 주제든 상관없다.

자유롭게 만들되, 아래 목표들은 반드시 달성해야 한다:

- TypeScript를 사용한다.
- React Router를 활용한 다중 페이지 애플리케이션 구성
- 사용자 경험 및 웹 접근성 개선
- 테스트 코드 작성과 커버리지 향상

# 🎬 FlixDrop (플릭스드롭) — 오늘의 영화 룰렛 기획안

> **한 줄 요약**: "오늘 뭐 보지?" 고민하는 유저들을 위해 몇 가지 가벼운 취향 선택(장르, 연도, 평점)만으로 영화를 운세처럼 뽑아주고, 유튜브 쇼츠 스타일의 세로형 풀스크린 UI로 콘텐츠를 던져(Drop) 주는 미니 큐레이션 서비스입니다.

---

## 1. 프로젝트 개요

- **프로젝트명**: FlixDrop (플릭스드롭)
- **네이밍 이유**: 영화를 뜻하는 **Flix**와 유저의 취향에 딱 맞는 단 한 편의 콘텐츠를 화면에 툭 떨어뜨려 준다는 **Drop**을 합성했습니다. 수많은 리스트를 방황하는 유저에게 '에어드롭(AirDrop)'처럼 가장 직관적이고 빠르게 명작을 전달하겠다는 서비스 정체성을 담았습니다.
- **목적**: OTT 플랫폼의 선택 장애(Netflix Syndrome)를 해결하기 위해, 최소한의 취향 필터링만으로 단 한 편의 영화 비주얼을 쇼츠 스타일로 강렬하게 추천하는 서비스 제공
- **사용 API**: TMDB (The Movie Database) Discover API
- **진행 형태**: 개인 진행 (Greedy FE Advanced 미션 제출용)
- **기술 스택**: React + TypeScript, React Router v6, Axios 또는 Fetch API

---

## 2. 기획 의도 및 배경 (Why)

- **선택의 피로감**: OTT 플랫폼의 대중화로 콘텐츠는 넘쳐나지만, 정작 유저들은 수많은 리스트를 이리저리 방황하며 "무엇을 볼지 고르는 데" 너무 많은 에너지를 낭비합니다.
- **Pull에서 Push로**: 유저가 직접 영화 정보를 발굴하는 피로한 과정(Pull)을 전면 배제하고, 몇 가지 키워드만 고르면 서비스가 취향에 맞는 단 한 편의 영화를 강렬하게 밀어 넣어주는 경험(Push)을 제공하고자 합니다.
- **숏폼 트렌드의 결합**: 가로형 리스트 나열 대신 유저들이 가장 익숙하게 소비하는 유튜브 쇼츠/틱톡 스타일의 세로형 풀스크린 UX를 영화 추천에 결합하여 유저의 빠른 의사결정을 돕습니다.

---

## 3. API 정보 및 활용 계획

본 서비스는 전 세계 최대 규모의 영화 데이터베이스인 **TMDB (The Movie Database) 오픈 API**를 연동하여 순수 프론트엔드 환경에서 데이터를 호출합니다.

- **호출 엔드포인트**: `GET https://api.themoviedb.org/3/discover/movie`
- **응답 데이터 포맷**: JSON
- **명확한 파라미터 활용 매커니즘**:
  - `api_key`: 유저 인증 및 데이터 권한 획득 (환경변수 `.env` 처리)
  - `with_genres`: 유저가 선택한 장르 고유 ID 값 매핑 (예: 액션=28, 코미디=35)
  - `primary_release_date.gte` / `primary_release_date.lte`: 유저가 선택한 연도대의 시작일과 종료일 설정 (예: 2010년대 선택 시 `2010-01-01` ~ `2019-12-31`)
  - `vote_average.gte`: 유저가 선택한 최소 평점 제한 (예: 7.0점 이상)
  - `page`: 검색 조건에 맞는 전체 페이지 중 랜덤한 페이지 넘버를 동적으로 생성하여 호출함으로써, 매번 똑같은 영화가 나오는 것을 방지하고 진정한 '랜덤 룰렛'을 구현합니다.

---

## 4. 서비스 핵심 메커니즘 (User Flow)

1. **취향 커스텀 선택**: 유저는 메인 화면에서 현재 끌리는 **[장르 / 개봉 연도 / 최소 평점]** 3가지 조건을 가볍게 터치하여 선택합니다.
2. **럭키 드롭**: [영화 뽑기] 버튼을 누르면, 시스템이 지정된 3가지 조건 파라미터를 조합하여 TMDB API를 호출하고 결과 목록 중 한 편을 무작위로 추출합니다.
3. **쇼츠 매칭**: 추첨 완료 즉시 화면이 전환되며, 단 한 편의 영화 비주얼이 쇼츠 영상처럼 화면 전체를 가득 채우며 나타납니다.

## 5. MVP 기능 요구사항 (Functional Requirements)

### FR-1. 3대 취향 필터 셀렉터 (메인 화면)

- **기능**: 유저가 취향에 맞게 필터를 조합할 수 있도록 3가지 선택 영역을 제공합니다.
- **선택 데이터 옵션**:
  - **장르 (Genre)**: 액션, 코미디, 로맨스, 스릴러, SF 등 (단일 토글 칩 UI)
  - **연도대 (Era)**: 최신작(2020년대), 2010년대, 2000년대, 레트로(90년대 이전)
  - **평점 (Rating)**: 상관없음, 대중성 확보(7점 이상), 믿고 보는 명작(8점 이상)

### FR-2. 쇼츠형 풀스크린 결과 카드뷰 (결과 화면)

- **기능**: 뽑힌 단 한 편의 영화 고화질 포스터 데이터를 모바일 규격의 세로형 풀스크린 (`100vh`)으로 꽉 차게 연출합니다.
- **기획 디테일**:
  - 포스터 이미지 위에 어두운 그라데이션 레이어를 덮어씌워 텍스트 가독성을 확보합니다.
  - 실제 숏폼 UI처럼 화면 최하단 영역에 영화 제목, 개봉일, 평점, 한 줄 줄거리(Overview)를 자막 레이어 형태로 얹어 표현합니다.
  - 다른 영화 리스트를 가로로 나열하지 않고, 오직 단 한 편에만 시선이 꽂히도록 시각을 제한합니다.

### FR-3. 무한 루프 액션 (다시 뽑기 및 뒤로 가기)

- **기능**: 뽑힌 영화가 마음에 들지 않을 때 화면 흐름을 깨지 않고 동일한 조건으로 즉시 재추첨하는 [다시 뽑기 🔄] 버튼과, 조건을 처음부터 다시 고를 수 있는 [필터 변경 🏠] 버튼을 하단에 배치합니다.
